# ARTASIMN

Полная новая концепция сайта — статика (HTML/CSS/JS, без сборки), готовая к
бесплатному деплою на Vercel.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная. Под шапкой — полоса из 4 фото-меню (Jewellery / Garment / Tattoo / Tatto Office), каждое залито чёрной виньеткой, при наведении виньетка снимается. Ниже — сетка товаров. |
| `items.html` | Просто весь каталог одной сеткой, без фильтра. |
| `product.html?id=…` | Карточка товара: галерея, материал, `ORDER` / `+ ADD TO CARD`. |

## Меню под шапкой

- **Jewellery** / **Garment** — фильтруют сетку на главной (`index.html?cat=jewellery` / `?cat=garment`); активная плитка остаётся без виньетки.
- **Tattoo** / **Tatto Office** — ведут на внешний `tattoo-office.com`.

Кнопки `tattoo` и `a.dept` в шапке — внешние ссылки на `tattoo-office.com` и
`artasimn-department.com` соответственно.

## Наведение на товар — скраб по фото

Курсор двигается по ширине карточки — доля X определяет, какое из фото
товара показать (как на mozij.ru). Один товар может иметь от 2 до 4 фото;
точки под карточкой показывают, какое фото активно.

## Портфолио-карточка эскиза

Последняя карточка на главной (без фильтра) — эскиз тату `эскиз.png`, без
цены и кнопки корзины. Клик открывает его крупно в лайтбоксе.

## Структура

```
index.html  items.html  product.html
css/style.css
js/data.js   — каталог товаров, меню, эскиз
js/site.js   — шапка, футер, карточки, скраб-хавер, лайтбокс
assets/
  logo.svg           — логотип (вордмарк)
  favicon.svg        — фавикон из репозитория
  menu/              — 4 фото под шапкой
  products/<slug>/   — фото товаров по папкам
  sketches/          — эскизы
vercel.json
```

## Известные пробелы

- Товара **Endless Knot Kongo** (серьга, 10 000 р) нет — фото не найдено в
  переданных файлах, добавить легко через `js/data.js`.
- Раздел `card` (корзина) — заглушка.

## Локальный запуск

```bash
npx http-server -p 8080
```
